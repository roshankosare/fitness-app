# 🏋️ Fitness Web App — Setup

## prerequisites

1. git
2. Node 22.0v
3. mysql

### clone the repo

```
#ssh
git clone  git@github.com:roshankosare/fitness-app.git

#http
git clone https://github.com/roshankosare/fitness-app.git

```

### install dependencies

```
npm install

```


### generate prisma lib
```
npx prisma generate

```

### deploy migrations
``` 
npx prisma migrate deploy

```

### start project

```
npm run dev

```
